Comparison of the COSMOS-posterior-trained flow to template-fitting baselines

Evaluation population: same 5,083 secure-spec test IDs from the revised clean
HSC i<25 AB (2 arcsec aperture), i S/N>=5 experiment. No test-object removal,
photo-z agreement cut, test-label calibration or hyperparameter optimization.
The population is the spectroscopic overlap, not a representative photometric
or Rubin sample. All flow checkpoints are the previously saved models.

1. Released COSMOS2020 Classic LePhare
   Exact ID matches to cached released PDFs, normalized by trapezoid integration.
   Piecewise-linear PDF density and exact within-cell CDF integration. All main
   rows use posterior medians and equal-tailed 68% and 95% intervals. The published
   catalog lp_zpdf point estimate is scored separately as a consistency check.
   This LePhare run uses the full deep multiwavelength COSMOS photometry: it is
   the flow's teacher and an information-rich reference, not an equal-input
   competitor. Its spectroscopy-based template/zero-point calibration may
   include test objects; independence has not been audited. Grid dz=0.01 limits
   uncertainty accuracy for narrow PDFs. No PDF recalibration is applied.

2. Six-band EAZY-py 0.8.7
   Uses the EXACT previously saved noisy CFHT-u / HSC-grizy test fluxes/errors.
   Negative fluxes are retained; all six measurements are used. No spectroscopic
   label is supplied in its catalog. Measured EBV from the same COSMOS catalog
   is applied to fluxes and errors using the published preparation coefficients:
   [4.807,3.69,2.715,2.0,1.515,1.298]. Common aperture-to-total scaling is not
   needed for this free-amplitude template fit with no magnitude prior.
   Public EAZY filters: 409 (CFHT cfh9302 u), 314-318 (HSC grizy). These are
   library native-band responses, not exact exposure-dependent passbands.
   EAZY's standard 12 tweaked FSPS templates are combined nonnegatively (NNLS).
   Parameters: SYS_ERR=0.01, TEMP_ERR_A2=0.20, template_error_10.def; IGM enabled,
   CGM disabled; z=0.001..10, logarithmic step dz/(1+z)=0.005.
   First run: flat redshift prior, no beta prior. The installed default H160 magnitude
   prior is inapplicable to these six optical filters. No replacement prior
   was fitted, and no zero-point/template recalibration was performed.
   Main comparison uses posterior medians; EAZY's interpolated maximum-posterior
   point is also reported separately. Template fitting is configuration- and
   prior-dependent. This is an initial untuned baseline, not a best-performance
   EAZY or LePhare six-band benchmark.

   Prior-sensitivity run (--r-prior): apply the supplied prior_R_zmax7.dat to
   HSC r, with the catalog total_off2 correction applied as a common scale to
   all fluxes/errors to obtain total magnitudes. The R-to-HSC-r mapping and the
   prior population are approximate, not recalibrated on test labels. The prior
   magnitude range is 20..27.5; EAZY clips out-of-range magnitudes and applies
   its default prior floor 0.01. The raw prior's first header line is prefixed
   with '#' in a separate copy to make it readable by EAZY-py; numeric values
   are unmodified. The saved flat-run chi2 grid is reused: common flux/error
   scaling is absorbed by free template amplitudes and leaves chi2 invariant.
   EAZY recomputes its likelihood normalization and prior for this run.

Metrics: r=(posterior median - zspec)/(1+zspec); bias=median(r),
NMAD=1.4826*median(abs(r-median(r))), outlier fraction=mean(abs(r)>0.15).
Coverage uses quantiles [0.16,0.84] and [0.025,0.975]. Point estimate and PDF
calibration are separate properties. Coverage near nominal alone does not
establish full posterior calibration or remove spectroscopic selection bias.
Paired bootstrap: 300 test-galaxy resamples, seed 20261116. It omits training
seed variance, spatial covariance, and spectroscopic selection effects.

Run with requirements/requirements-flow.txt plus eazy==0.8.7, scipy==1.18.1,
dust_extinction==1.7, extinction==0.4.10, h5py==3.16.0 installed:
  python bin/run_eazy_baseline.py --limit 25  # smoke run, separate products
  python bin/run_eazy_baseline.py
  python bin/run_eazy_baseline.py --r-prior
  python bin/compare_template_baselines.py
Without EAZY outputs the comparison script still scores released LePhare.

Results: results/template_comparison contains same-ID metrics, binned metrics,
posterior quantiles/PITs, EAZY fit PDFs/chi2 grid, parameters, and comparison plots.
The original flow experiment remains unchanged. These are native-filter noisy
proxy data; no actual Rubin catalog or LSST response integration was used.
