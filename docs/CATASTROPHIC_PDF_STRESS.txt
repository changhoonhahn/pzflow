Random catastrophic teacher-PDF injection (test 1)

Run bin/catastrophic_pdf_stress.py in the existing full data workspace.
It resumes completed scenarios. Defaults train all twelve fraction/weight
combinations, retaining the original maximum budget and clean validation PDFs.
No original results or model checkpoints are overwritten.

Affected fractions: 1%, 3%, 5%, 10% of 111,952 training galaxies.
Wrong-mode PDF weights: 25%, 50%, 100%; the zero-injection baseline is shared.
Each affected PDF is (1-weight)*original+weight*g, where g is a narrow
truncated Gaussian at a distant training-galaxy photo-z median. No spec-z is
used to construct the corruption. The maximal affected subset is randomly
ranked once, with nested subsets for smaller rates. Selected IDs remain fixed
throughout training. The mixture branch is resampled for each posterior draw,
as required by the specified probability distribution.

Training galaxies, six-band photometry/errors, augmentation, spatial splits,
model architecture, initial weights, optimizer, and stopping rules are paired
with the original fit. An independent RNG generates injection draws without
changing the original RNG's sequence of batches, base PDF draws, or flux noise.
Validation uses the original uncorrupted teacher PDFs; test uses the exact
saved 5,083-galaxy noisy photometry realization. Training may stop at different
epochs because the clean validation loss changes under contamination.

Run bin/analyze_catastrophic_pdf_stress.py after the full sweep finishes.
It saves compact plotting inputs and a standalone figure notebook in
results/catastrophic_pdf_stress. Execute that notebook to compute paired
bootstrap intervals and regenerate the response, magnitude, and PIT figures.

Scientific limits: one paired training seed and one corruption realization;
existing COSMOS teacher errors remain in the baseline; teacher-relative
corruptions need not always disagree with unknown true redshifts; the selected
spectroscopic test population is not representative. Bootstrap intervals are
conditional on the trained models and exclude training and pattern variance.
These runs contain no n(z) reweighting and use the existing CFHT/HSC-filter
LSST-like noise proxy, rather than measured Rubin photometry.
